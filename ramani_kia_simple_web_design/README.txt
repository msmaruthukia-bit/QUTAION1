RAMANI KIA SIMPLE HTML + CSS WEBSITE
====================================

CONTENTS
- index.html: all page text, customer fields, vehicle model list, pricing table and live map.
- style.css: colors, sizing, responsive layout and print styling.
- images/kia-logo.svg: local logo-style asset.
- images/car-placeholder.svg: local car illustration; replace with an approved vehicle photo.
- images/map-preview.svg: offline map-style preview asset.
- images/design-reference.png: design reference screenshot, if included.

HOW TO RUN
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge or Firefox.
3. To permanently change wording, open index.html in Notepad, Notepad++ or VS Code, edit the text and save.
4. Edit style.css to change colours and layout.
5. Price cells can also be clicked and edited temporarily in the browser.
6. Use Print / Save PDF to print the quotation.

MAP
The embedded Google Maps frame and Open in Google Maps link need an internet connection. It searches for
"Ramani Kia Kumbakonam" rather than claiming a verified pin coordinate. Confirm the dealership pin before
sending the page to customers.

IMAGES
The included car illustration is a placeholder. Replace images/car-placeholder.svg with a photo file you
are permitted to use, and change the img src in index.html to that filename. Keep image files in images/.

IMPORTANT
This is a static template. Prices are blank on purpose: enter the current approved values before sharing
a quotation. No backend or installation is required.
